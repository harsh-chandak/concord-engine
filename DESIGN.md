# concord-engine-v2

Ship the full loop — contract, bind, brief, fan out, gate, verify, document, account — with the package never calling a model.

## Scope

**In.** MCP tools for every loop command; the skill that drives the loop inside Claude Code; unit tests for contract validation, briefing, waves, acceptance and cost; README rewritten around the loop; an end-to-end shell matrix for the loop

**Out.** spawning worker processes — the host spawns, the package briefs; authoring contracts — the agent authors, the package validates; counting real tokens — no tokenizer ships, estimates are labelled; retrying failed workers

### convention

- **how token figures are presented** — `every token figure is labelled an estimate and states its chars-per-token assumption`
  the package measures bytes; calling bytes tokens would be the kind of unsourced number this project exists to avoid  
  <sub>d-004 · contract:concord-engine-v2 (pm) · 2026-10-16T20:32:17.981Z</sub>
- **model calls inside the package** — `no file in the package may call a model or open a network connection; enforced by a test`
  the one defensible sentence is that agreement is decided by comparison, never by a model — if authoring moves inside the package that stops being true  
  <sub>d-001 · contract:concord-engine-v2 (pm) · 2026-10-16T20:32:17.978Z</sub>

### naming

- **cli command that runs acceptance checks** — `accept`
  verify already means route verification in v0.1 and renaming it would break installed users  
  <sub>d-003 · contract:concord-engine-v2 (pm) · 2026-10-16T20:32:17.980Z</sub>
- **cli flag for selecting a contract** — `--contract`
  every loop command takes it, so it has to be the same word everywhere  
  <sub>d-002 · contract:concord-engine-v2 (pm) · 2026-10-16T20:32:17.980Z</sub>
- **mcp tool name prefix for loop tools** — `no prefix; tool names are write_contract, bind_contract, brief_unit, fleet_plan, run_acceptance, generate_docs, cost_report`
  the existing five tools carry no prefix, and mixing conventions inside one server is the drift this tool exists to catch  
  <sub>d-005 · contract:concord-engine-v2 (pm) · 2026-10-16T20:32:17.981Z</sub>
